# Projeto_CGTok
Projeto direcionado a apresentação do CGTEC 2026.

OBJETIVO:
O projeto foi criado para a apresentação do CGTEC de 2026. Se baseia em um site com vídeos de diferentes tipos de conteúdos para que o usuário passe um tempo estabelecido assistindo. Após isso ele irá responder a um questionário contendo perguntas de conhecimento geral e relacionadas a alguns vídeos que apareceram. Com isso será possível realizar uma análise para entender como está a retenção de atenção dos participantes,a efetividade do sistema de recompensa e o impacto do conteúdo Slop oriundo de vídeos feitos com IA na mente das pessoas.

INSTRUÇÕES PARA O GRUPO:
Assets - Tudo que é usado na interface (Imagens, vídeos, tipografias, e outros);
Includes - Trechos de código que podem ser reutilizados em várias partes;
Views - É onde fica tudo de mais importante do projeto (as páginas).
